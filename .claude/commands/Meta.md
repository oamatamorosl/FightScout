# Meta Tags - TechFix Agenda

Etiquetas `<meta>` utilizadas en [index.html](index.html) para SEO y compartición en redes sociales (Open Graph / Twitter Card).

```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>TechFix Agenda | Soporte L2 y Mantenimiento IT</title>

<meta name="description" content="Agenda tus tickets de soporte técnico de nivel 2, mantenimiento de hardware y gestión de redes.">
<meta property="og:title" content="TechFix Agenda - Soporte IT">
<meta property="og:description" content="Portal de gestión de incidentes y mantenimiento de infraestructura IT.">
<meta property="og:image" content="https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcTkyd2qqFYvXrhT2fahT9oCa3J8gouzWzMSscxQpBP7wg&s=10">
<meta property="og:type" content="website">
<meta name="twitter:card" content="summary_large_image">
```

## Detalle

| Etiqueta | Propósito |
|---|---|
| `charset` | Codificación de caracteres UTF-8 |
| `viewport` | Diseño responsive en móviles |
| `title` | Título mostrado en la pestaña del navegador |
| `description` | Descripción para motores de búsqueda |
| `og:title` | Título al compartir en redes sociales |
| `og:description` | Descripción al compartir en redes sociales |
| `og:image` | Imagen de vista previa al compartir |
| `og:type` | Tipo de contenido Open Graph |
| `twitter:card` | Formato de tarjeta al compartir en Twitter/X |

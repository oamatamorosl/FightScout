Espaciado

Nueva para el backoffice: el --espacio-* del sitio público combina valores múltiplo de 4 (4, 8, 12, 16...) con otros que no lo son (6, 10, 14, 18, 22, 30, 50, 90px). Esta escala es estrictamente múltiplo de 4.

8 pasos: de ajustes finos entre ícono y texto hasta separación entre secciones.

--espacio-4
4px · entre ícono y texto
--espacio-8
8px · dentro de un control
--espacio-12
12px · entre controles relacionados
--espacio-16
16px · padding estándar de tarjeta
--espacio-24
24px · entre bloques de una tarjeta
--espacio-32
32px · entre tarjetas de una grilla
--espacio-48
48px · entre paneles
--espacio-64
64px · entre secciones de página
